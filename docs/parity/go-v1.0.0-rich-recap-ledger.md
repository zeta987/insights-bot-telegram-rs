# Go v1.0.0 Rich Recap Parity Ledger

Source release: `insights-bot-go` commit `02aee8ce260165592e2152eb5a024a602e4eced1`.

This ledger is the implementation boundary for the Rich Message recap port.  Each
stable identifier is retained when its owning module changes.  `/smr` generation
is deliberately absent; `smr/summarization/feedback/react` appears only as the
required recap-button compatibility callback.
